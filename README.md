# 3LABABEE AI Product Post Generator

A web app that turns a product photo into a finished, on-brand square (1:1) 3LABABEE advertisement.

You upload a product image. The server sends it to an AI image model on [OpenRouter](https://openrouter.ai) together with the fixed 3LABABEE master template. The browser then lays the brand text, logo areas and your real QR code on top of the generated image, and you download the result as a PNG.

The interface is available in English and Arabic (RTL).

## How it works

1. **Upload**: the user picks a product image (PNG, JPEG or WebP, max 20 MB), an AI model and a resolution.
2. **Generate**: `POST /api/generate-post` sends the master template (`public/template.png`) and the product photo to `https://openrouter.ai/api/v1/images` with a prompt focused on product accuracy.
3. **Restore branding**: the browser copies the original template art back over the protected brand areas (`BRAND_REGIONS`), so the AI can't change the logo or layout.
4. **Draw text**: the headline, subtitle and QR label are drawn on the canvas from code (`TEXT_LAYERS`), not generated by the AI.
5. **Add QR**: the uploaded QR code is drawn pixel-for-pixel into `QR_BOX`. It is never sent to the AI, so it stays scannable.
6. **Download**: the finished poster is exported as a PNG.

### Available models

| Model ID | Label |
| --- | --- |
| `google/gemini-3.1-flash-image` | Nano Banana 2 · Standard (default) |
| `google/gemini-3-pro-image` | Gemini 3 Pro Image · Premium |
| `google/gemini-3.1-flash-lite-image` | Nano Banana 2 Lite · Economy (always 1K) |

The supported resolutions are `1K`, `2K` and `4K`. When OpenRouter reports the cost of a generation, the UI shows it.

## Running locally

You need Node.js 20 or newer and an OpenRouter API key.

```bash
cd 3LABABEE_OpenRouter_Production_Render/3lababee-openrouter-production
npm install
```

Copy `.env.example` to `.env` in that folder, then put your real OpenRouter key in it:

```env
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxx
PORT=3000
# Optional: public URL sent to OpenRouter as the referer
# APP_URL=http://localhost:3000
```

Then start the server:

```bash
npm start      # or: npm run dev (restarts when files change)
```

Open <http://localhost:3000>.

> **Keep the API key server-side.** Never put it in `public/` or commit `.env` to git.

## API

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/health` | Health check, returns `{"ok":true}` |
| `GET` | `/api/config` | Says whether the API key is set, and lists the available models |
| `POST` | `/api/generate-post` | Multipart form with `product` (file), `model` and `resolution`. Returns the generated image. Response headers `X-3LABABEE-Model` and `X-OpenRouter-Cost` (when available) |

## Deployment

The app is set up for [Render](https://render.com) through `render.yaml`. Set `OPENROUTER_API_KEY` and `APP_URL` in the Render dashboard, and don't set `PORT` because Render provides it. See [PUBLISH_RENDER.md](3LABABEE_OpenRouter_Production_Render/3lababee-openrouter-production/PUBLISH_RENDER.md) for the full steps and troubleshooting.

## Customizing

- **Text, fonts, colors**: edit `TEXT_LAYERS` in `public/app.js`.
- **Template**: replace `public/template.png` with a text-free version, then adjust `BRAND_REGIONS` and `QR_BOX` in `public/app.js` if the layout moved.
- **AI behavior**: edit `MERGE_PROMPT` in `server.js`.
- **Translations**: edit `public/i18n.js`.

More detail is in the app's own [README](3LABABEE_OpenRouter_Production_Render/3lababee-openrouter-production/README.md).
